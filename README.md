# Dominic Savio — Developer Portfolio

A professional, production-ready portfolio website representing a Full-Stack Developer, Django Engineer, and AI-Integrated Application Builder.

## 🚀 Features

- **Recruiter-focused Design**: Engineered to answer key recruiter questions in under 60 seconds (Who is he, What does he know, What has he built, Should he be interviewed).
- **Aesthetic Excellence**: Built with a custom, tailored navy/electric blue color palette, rich interactive cards, modern layouts, and subtle animations.
- **CampSpark ERP Case Study**: Interactive showcasing of a full-featured college management system built solo with Django (15+ modules, 50+ DB models, 100+ screens).
- **Core Strengths & Skills**: Clear documentation of backend engineering, system design, databases, cloud deployment, and AI integration capabilities.
- **GitHub & Open Source Showcase**: Dynamic profile card, live contribution activity mock grid, and repositories list.
- **High Performance & Accessibility**: Fast loading static structure, SEO optimized tags, proper headers, semantic HTML, and accessibility checking (`prefers-reduced-motion` detection).

## 🛠️ Technology Stack

- **Structure**: HTML5 (Semantic elements only)
- **Styling**: CSS3 (Custom properties, grid, flexbox, custom scrollbars, transitions)
- **Framework**: Bootstrap 5.3.3 CSS via CDN
- **Interactions**: Vanilla JavaScript (ES6+ only, no external libraries)

## 🌐 Deployment Instructions

This website runs as a completely static site and can be deployed without modifications on any web host.

### GitHub Pages (Recommended)
1. Push this repository to your GitHub account under your username, e.g., `Dominicsavio6506/dominicsavio6506.github.io`.
2. Go to **Settings > Pages** on your GitHub repository.
3. Under **Build and deployment**, set Source to **Deploy from a branch** and select the `main` or `master` branch.
4. Click **Save**. Your site will be live at `https://dominicsavio6506.github.io/` in a few minutes.

### Vercel / Netlify
1. Log in to Vercel or Netlify.
2. Select **Add New Project** and import your GitHub repository.
3. Keep build settings at default (leave Build Command empty, publish directory as root `./`).
4. Click **Deploy**.
