Featured Project

CampSpark ERP System

A full-featured college management platform built solo with Django — 15+ modules, 50+ database models, 100+ screens.

Python Django Bootstrap JavaScript PostgreSQL Railway

CampSpark is a comprehensive ERP system built to manage the complete operational workflow of a college. From student enrollment to fee collection, attendance tracking, event coordination, and library management — every process runs through a single integrated platform.

The system features role-based access control with separate dashboards for students, staff, and administrators. A smart notification engine delivers contextual daily reminders based on each user's role and pending actions. An AI-powered complaint analysis module processes metadata without ever exposing private complaint content.

Integrated Modules
